# SO-101 Visual Assets

This directory vendors the SO-101 visual URDF and STL meshes used by the
Electron calibration viewer.

Source:

```text
https://github.com/TheRobotStudio/SO-ARM100
Simulation/SO101/so101_new_calib.urdf
Simulation/SO101/assets/*.stl
```

The repo's kinematics code still uses `assets/kinematics/so101_kinematics.urdf`.
These assets are for visual calibration guidance only.
